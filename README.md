# Studies Of ...

Take inspiration from Jen Simmons' design lab: [https://labs.jensimmons.com/](https://labs.jensimmons.com/#flexibility).

Each table will create a Checkers Club website, when considering contrast, repetition, alignment, and proximity with regards to either a design informed by a study of verticality, overlap, whitespace, or density as a guiding prompt.

We will start this "study of ..." today in class and finish them next week.

I've included some initial typography scheme code in the CSS file. But, file free to swap and change values to meet the CRAP design principled approach.

1. Sketch a wireframe on your whiteboard.

  - Overlap

  - Density
